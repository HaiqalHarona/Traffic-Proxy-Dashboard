  - "traffic-proxy.enable=true"
  - "traffic-proxy.rule=app.local"
  - "traffic-proxy.port=8080"  # optional, falls back to exposed port or 80

Docker Engine Discovery Mechanism

Pluggable discovery provider inspecting containers over read-only Docker daemon socket

Provider Specifications

Provider Interface: internal/discovery.Provider
Active Driver: DockerProvider
Socket Endpoint: unix:///var/run/docker.sock
Mount Permission: :ro (Strictly Read-Only)
Scan Cadence: 5 seconds (time.Ticker)
Target Resolution: Bridge Network IP + Port

Supported Container Labels

traffic-proxy.enable REQUIRED

Must be set to "true" to include in proxy router

traffic-proxy.rule REQUIRED

Virtual host matching rule (e.g. app.local, api.domain.com)

traffic-proxy.port OPTIONAL

Internal target port (defaults to exposed port or 80)

COMPLETE DOCKER COMPOSE EXAMPLE 
version: '3.8'
services:
  traffic-proxy:
    image: ghcr.io/haiqalharona/traffic-proxy:latest
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock:ro
    read_only: true
    security_opt:
      - no-new-privileges:true

  my-app:
    image: hashicorp/http-echo:0.2.3
    command: ["-text=Hello World", "-listen=:5678"]
    labels:
      - "traffic-proxy.enable=true"
      - "traffic-proxy.rule=hello.local"
      - "traffic-proxy.port=5678"

Executing TrafficGen from Terminal

Run the bundled Go generator to test concurrency throttling, SSE streaming, and route isolation:

# 1. Start traffic generator with 20 workers for 30 seconds:
go run ./cmd/trafficgen -target=http://localhost:80 -concurrency=20 -duration=30s
# 2. Or trigger the automated seed script:
bash scripts/seed-traffic.sh
TrafficGen dispatches requests across four target profiles:
  • app.local: 80% distribution (Normal 200 OK throughput)
  • slow.local: 10% distribution (Deliberate 200ms delay to exercise queues)
  • unknown.local: 10% distribution (Validates 502 Bad Gateway handling)
