# Plan Artifacts Standards

All planning roadmaps, architectural specifications, and subagent handoff documents generated by agents must strictly adhere to the following rules:

## 1. Storage Location
- All markdown plans must be exported directly to the root `artifacts/` directory (`/artifacts/`).
- Never export plan files to the root directory, `doc/`, or external folders outside the repository workspace.

## 2. File Naming Convention (UPPER_SNAKE_CASE)
- Every markdown plan file name MUST strictly use **UPPER_SNAKE_CASE** with the `.md` extension.
- Valid Examples:
  - `artifacts/PLAN_WEBSOCKET_SUPPORT.md`
  - `artifacts/PLAN_RATE_LIMITING.md`
  - `artifacts/AUDIT_CONCURRENCY_STREAMING.md`
  - `artifacts/HANDOFF_NET_CORE.md`
- Invalid Examples:
  - `artifacts/plan-websocket.md` (kebab-case prohibited)
  - `artifacts/planWebsocket.md` (camelCase prohibited)
  - `artifacts/Plan_Websocket.md` (mixed case prohibited)

## 3. Gitignore Enforcement
- The root `artifacts/` directory is gitignored via `.gitignore` to prevent transient plans from polluting source control history.
- Never force-add (`git add -f`) files located inside `artifacts/`.
